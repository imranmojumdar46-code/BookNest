About BookNest

A community book store and library where readers share the books they love.

Our story

BookNest started as a full-stack learning project: a real web application with a front end, a Python back end and a database. Members can register, log in and manage their own listings, while visitors can browse and search the catalogue.

Every feature — from login sessions to book management — is built the way production sites do it, just small enough to understand end to end.

How a request travels

  1. The browser sends a request (HTML, CSS and JavaScript on the front end).
  2. A Flask route receives it, a controller validates the input and checks the login session.
  3. The controller reads or writes the SQLite database.
  4. Flask renders an HTML page and sends it back.
